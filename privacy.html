Privacy policy

Last updated 28 October 2026.

Workspace MCP is a personal tool used only by its owner, Daniel J Hu, with his own Google accounts.

What it accesses

With the owner's permission, it reads and changes Gmail messages, Google Calendar events and Google Drive files in the owner's own accounts.

How the data is used and stored

Data is used only to carry out the owner's own requests. Sign-in tokens are stored only on the owner's computer. Google user data is not sold, not used for advertising and not shared with anyone else, except as needed to process the owner's requests through the AI assistant he has chosen. Use of data received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions.
